# penpapertech Homebrew tap

```sh
brew install penpapertech/tap/wormhole
```

[wormhole](https://github.com/penpapertech/wormhole) sends files and folders peer to peer
across NATs with a short code. Works on macOS (Apple Silicon and Intel) and Linux (x86_64 and
ARM64). Update with `brew upgrade`.

Use the full name `penpapertech/tap/wormhole`: a plain `brew install wormhole` installs an
unrelated app with the same name.

The formula is updated automatically by the wormhole release workflow.
